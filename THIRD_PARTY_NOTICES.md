## YuE style tags

`apps/ttb-studio/src/lib/client/style-tags.ts` contains style tags curated from `top_200_tags.json` in
YuE (https://github.com/multimodal-art-projection/YuE/tree/YuE-v1), Copyright the YuE authors
(Multimodal Art Projection), licensed under the Apache License, Version 2.0
(https://www.apache.org/licenses/LICENSE-2.0). Changes: tags were lower-cased, duplicates merged,
unclear and non-musical entries removed, and additional genres, instruments and tempo/era tags
added. Only the tag list is used; no YuE code or model weights are included.
